# Швидке встановлення (OcStore 3.0.4.1)

1. Завантажте файли з `upload/` у корінь сайту.
2. Адмін → Доповнення → Встановлення доповнень → завантажити `install.xml`.
3. Менеджер доповнень → Оновити.
4. Доповнення → Доставка → Укрпошта API → Встановити.
5. Вказати Bearer eCom, StatusTracking Bearer, User token, UUID відправника, індекс.
6. Увімкнути статус і способи W2W/W2D.

## Перше відправлення в sandbox

1. Увімкніть Sandbox.
2. Створіть тестове замовлення з доставкою Укрпошта.
3. У картці замовлення натисніть «Створити ТТН».
4. Перевірте ярлик PDF і ШКІ.

Токени: договір з Укрпоштою → додаток з Bearer / token → [документація](https://dev.ukrposhta.ua/documentation).
