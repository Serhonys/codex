# Швидке встановлення (OcStore 3.0.4.1 / OpenCart 3.x)

## Важливо

Завантажуйте файл **`ukrposhta-api.ocmod.zip`** (у корені архіву мають бути `upload/` і `install.xml`, без зайвої обгортки).

## Кроки

1. Адмін → **Доповнення → Встановлення доповнень** → завантажити `ukrposhta-api.ocmod.zip`.
2. Якщо інсталер OcStore не приймає zip — розпакуйте і скопіюйте вміст папки `upload/` у корінь сайту (поруч із `admin/`, `catalog/`, `system/`).
3. Окремо: **Доповнення → Встановлення доповнень** → завантажити лише `install.xml` (або він уже всередині ocmod.zip).
4. **Доповнення → Менеджер доповнень** → кнопка **Оновити** (синя).
5. **Доповнення → Доставка** (тип: Доставка) → знайти **Укрпошта API** → зелений **+** (Встановити).
6. Натиснути **Редагувати (олівець)** → **Статус = Увімкнено** → зберегти.

Перевірка, що файли на місці (FTP/файловий менеджер):

```
admin/controller/extension/shipping/ukrposhta.php
catalog/model/extension/shipping/ukrposhta.php
system/library/ukrposhta/api.php
```

Якщо цих файлів немає — модуль **не з’явиться** у списку доставок.

## На вітрині (checkout) не видно?

1. Статус модуля = Увімкнено.
2. Увімкнені способи (Експрес відділення / курʼєр тощо).
3. Країна доставки = Україна (або ваша geo-зона).
4. Очистіть кеш OcStore / модифікацій.
5. Без токенів API все одно має показуватись резервна ціна доставки.

## Токени API

Bearer eCom, StatusTracking Bearer, User token, UUID відправника — з договору Укрпошти:
